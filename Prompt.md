# Multi-Step Onboarding Form

## Project Overview
A React-based registration application that allows users to complete the onboarding process through three simple steps.

## Phase 1: Basic Form
- Step 1: First Name, Last Name and Date of Birth.
- Step 2: Email, Password and Confirm Password.
- Step 3: Review and Submit.
- Next and Back navigation.
- Preserve data between steps.
- Display success message after submission.

## Phase 2: Validation and UX
- Real-time email validation.
- Password minimum 8 characters.
- Confirm Password must match.
- Disable Next button for invalid fields.
- Show/Hide password option.
- Dynamic progress bar.

## Phase 3: Enterprise Architecture
- Use React Hook Form for form handling.
- Use Zod for schema validation.
- Maintain reusable components.
- Keep code clean and beginner-friendly.
